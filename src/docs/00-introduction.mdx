# @craftzbay/ui

A refined-minimal Tailwind v4 + React design system. 49 accessible primitives,
8 ready-made page patterns, dark mode out of the box. MIT licensed.

- **npm:** `pnpm add @craftzbay/ui`
- **GitHub:** [craftzbay/design-system](https://github.com/craftzbay/design-system)
- **Showcase:** [design.runestonetechnologies.com](https://design.runestonetechnologies.com)

---

## What's inside

| Layer | What | Where |
|---|---|---|
| **Tokens** | Tailwind v4 `@theme` block — color, type, space, radius, motion | `src/styles/globals.css` |
| **Primitives** | 49 components built on Radix UI + cmdk + vaul | `src/components/ui/` |
| **Patterns** | 8 composed page layouts (auth, dashboard, settings, data table…) | `src/components/patterns/` |
| **Illustrations** | 6 line-art SVGs for empty / error states | `src/illustrations/` |
| **Hooks** | `useToast`, `useMediaQuery`, `useSidebar`, `useCommandPaletteShortcut` | `src/hooks/`, primitives |

## Aesthetic direction

> Linear, Vercel, Stripe Dashboard, Notion, Raycast — side by side.
> Neutral-dominant, one accent, hairline borders, generous whitespace,
> fast quiet motion.

The detailed rules are in [`docs/PHILOSOPHY.md`](https://github.com/craftzbay/design-system/blob/main/docs/PHILOSOPHY.md)
in the repo. The short version:

- 85% of any screen is neutral. Colour appears on action, status, and focus only.
- Borders are 1px hairlines. Shadows are restrained.
- Components ship every state out of the box: default, hover, focus-visible,
  active, disabled, loading, error.
- One accent per surface. No decorative gradients. No drop-shadows on text.

## Browser support

ES2022 / modern evergreen browsers. Tree-shakeable ESM + CJS + .d.ts.
