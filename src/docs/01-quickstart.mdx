# Quick start

## Install

```bash
pnpm add @craftzbay/ui
# or
npm install @craftzbay/ui
```

Peer dependencies (provide them in your app): `react@>=18`, `react-dom@>=18`.

## Import the stylesheet

Once, at the top of your app entry:

```ts
import '@craftzbay/ui/styles.css';
```

This loads the compiled Tailwind v4 token layer + Radix-friendly resets.
No extra Tailwind config required in your consumer app — the components
ship with their utilities already built in.

## Use a component

```tsx
import { Button, Dialog, DialogContent, DialogTrigger, DialogTitle } from '@craftzbay/ui';

export function ExportDialog() {
  return (
    <Dialog>
      <DialogTrigger asChild>
        <Button>Export…</Button>
      </DialogTrigger>
      <DialogContent>
        <DialogTitle>Export workspace</DialogTitle>
        ...
      </DialogContent>
    </Dialog>
  );
}
```

## Set up dark mode

Toggle `dark` class anywhere up the tree:

```tsx
<html className={prefersDark ? 'dark' : ''}>...</html>
```

The class can sit on `<html>` (recommended), `<body>`, or any container.
All token-coloured surfaces flip automatically.
